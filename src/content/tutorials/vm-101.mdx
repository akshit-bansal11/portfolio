## In one minute

<Logo tech="vm" label className="text-2xl" />

- A **virtual machine (VM)** is a computer made of software, running inside a real computer.
- It has its own operating system, its own files and its own pretend hardware.
- One real machine can run many VMs, each sealed off from the others.
- Almost every cloud server you can rent (AWS EC2, Azure Virtual Machines, Google Compute Engine) is a VM.

## What a VM really is

Say you have a Windows laptop and need to try Linux. You can buy a second computer, wipe your laptop, or run Linux **in a window** on the laptop you already have. A VM is that third option.

<Callout kind="insight" title="Why it says 'turn on virtualization in BIOS'">

Modern processors have built-in features for VMs: **Intel VT-x** and **AMD-V**. With them, the guest's code runs straight on the real CPU at close to full speed, and the hypervisor only steps in for sensitive operations. If the feature is switched off in your BIOS/UEFI settings, most hypervisors cannot start a VM at all, or run it very slowly.

</Callout>

## DIY walkthrough

You will launch a real Ubuntu VM with **Multipass**, a free tool from Canonical (the company behind Ubuntu), look inside it, and delete it.

<Callout kind="warn" title="Windows readers">

Commands assume PowerShell. In PowerShell, plain `curl` is not the real curl, so wherever you see `curl` type `curl.exe`. When a step says to create a file, create it with an editor such as VS Code and save it exactly where the title bar says. Keep the contents exactly as shown: indentation matters in YAML.

</Callout>

### Install Multipass

<Tabs group="os">
  <Tab label="Windows">

Multipass is Canonical's tool for quickly launching Ubuntu VMs. Its install page lists Windows 10 and 11 on Home, Pro and Enterprise as supported, from build 1809 up, and asks for the Virtual Machine Platform Windows feature to be enabled. You need administrator rights to run the installer. Download it from [canonical.com/multipass](https://canonical.com/multipass). I did not verify which hypervisor driver it uses on Home, so if launch fails, see the troubleshooting section.

  </Tab>
  <Tab label="macOS">

Download the installer from [canonical.com/multipass](https://canonical.com/multipass) and run it. You need an account with administrator rights.

  </Tab>
  <Tab label="Linux">

```bash
sudo snap install multipass
```

  </Tab>
</Tabs>

<Steps>
  <Step title="Launch a VM and time it" tone="violet" checkpoint="After a download on the first run, multipass list shows tutorial-vm as Running with an IP address.">

The first launch downloads an Ubuntu image, which takes a while. Launch is much quicker after that.

```bash
multipass launch --name tutorial-vm --cpus 1 --memory 1G --disk 5G
multipass list
```

  </Step>
  <Step title="Step inside" tone="violet" checkpoint="Your prompt changes to ubuntu@tutorial-vm. uname -r prints a kernel version, free -h shows about 1 GB of memory, and df -h shows a disk of about 5 GB. This is a complete computer with its own kernel.">

```bash
multipass shell tutorial-vm
uname -r
free -h
df -h
exit
```

Remember that kernel line. In [Docker 101](/tutorials/docker-101) you will see what a container reports instead.

  </Step>
  <Step title="Look at it from outside" tone="violet" checkpoint="multipass info shows the VM's state, IP address, memory and disk use. exec prints Ubuntu's release details without opening a shell. After stop, multipass list shows it as Stopped; after start, Running again.">

```bash
multipass info tutorial-vm
multipass exec tutorial-vm -- lsb_release -a
multipass stop tutorial-vm
multipass list
multipass start tutorial-vm
```

  </Step>
  <Step title="Throw it away" tone="violet" checkpoint="multipass list no longer shows tutorial-vm.">

```bash
multipass delete tutorial-vm --purge
multipass list
```

  </Step>
</Steps>

## Troubleshooting

<TroubleGroup title="Multipass and virtual machines">
  <Trouble
    symptom="multipass : The term 'multipass' is not recognized as the name of a cmdlet"
    cause="Multipass is not installed, or this terminal was opened before the install and has an old PATH."
  >

Close the terminal, open a new one and try `multipass version`. If it is still missing, run the installer again (Windows needs administrator rights).

  </Trouble>
  <Trouble
    symptom="multipass launch fails or hangs on Windows Home"
    cause="Multipass lists Windows Home as supported but needs the Virtual Machine Platform Windows feature, and hardware virtualization, to be on. I could not verify the exact message you will see, so check these first."
  >

Enable the feature from an administrator PowerShell, restart, and try again.

```powershell
Enable-WindowsOptionalFeature -Online -FeatureName VirtualMachinePlatform
```

If it still fails, try another machine. The diagrams above show the same idea.

  </Trouble>
</TroubleGroup>
